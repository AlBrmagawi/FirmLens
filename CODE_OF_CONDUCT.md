# Code of conduct

FirmwareLens welcomes contributors and users with different backgrounds and levels of experience. This code applies to the project's issues, pull requests, reviews and other project spaces.

## Expected behavior

- Be respectful and constructive. Discuss evidence and ideas without attacking people.
- Make room for questions, give actionable feedback and accept corrections.
- Respect privacy, research authorization and the licenses of shared materials.
- Keep examples reproducible and safe to share; use synthetic inputs when possible.

Harassment, discrimination, threats, sexualized conduct, unwanted contact, impersonation and publication of another person's private information are unacceptable. Do not use project spaces to solicit unauthorized access or disclose credentials and private firmware.

## Reporting and moderation

Use GitHub's **Report content** action on an issue, comment or pull request where available, or follow [GitHub's abuse reporting guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Reports made to GitHub are handled by GitHub; this project does not operate a separate private conduct-reporting inbox. Avoid repeating private information in public reports.

Maintainers may edit or remove inappropriate content, lock a conversation, or restrict participation using GitHub's moderation tools. Responses should consider the behavior, its impact and whether it is repeated. Community participation does not entitle anyone to harass maintainers or demand a response.

Software vulnerabilities have a separate private reporting channel described in [SECURITY.md](SECURITY.md).
